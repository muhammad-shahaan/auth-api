# Auth Practice API with AI Message Classification

A FastAPI backend project with Supabase authentication and an AI-powered message classification endpoint.

The project includes:

- User signup
- User login
- Protected routes
- Logout
- Supabase authentication
- AI message classification
- Structured AI output validation
- Timeout and retry handling
- AI kill switch
- Eight evaluation test cases

---

## Technologies Used

- Python
- FastAPI
- Supabase
- Groq API
- Pydantic
- Uvicorn
- python-dotenv
